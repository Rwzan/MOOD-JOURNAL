## ✨ Features

- 📝 **Easy Mood Tracking** - Log your daily emotions and thoughts
- 🎨 **Beautiful UI** - Modern, responsive design built with Tailwind CSS
- ⚡ **Lightning Fast** - Powered by Next.js 16 for optimal performance
- 🔒 **Type Safe** - Built with TypeScript (82.4% of codebase)
- 📱 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile
- 💭 **Reflections** - Review your mood patterns over time

## 🚀 Quick Start

### Prerequisites
- Node.js 18.17 or later
- npm, yarn, pnpm, or bun

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Rwzan/MOOD-JOURNAL.git
   cd MOOD-JOURNAL
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   # or
   bun install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   # or
   bun dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application running.

## 🛠️ Available Scripts

## 🎯 Getting Started with Development

### Editing Pages
The main page is located in `app/page.tsx`. The page automatically updates as you edit the file thanks to Next.js's hot module replacement.

### Adding New Components
Create reusable components in the `components/` directory and import them into your pages.

### Styling
This project uses **Tailwind CSS v4** with PostCSS. Add utility classes directly to your JSX elements for rapid styling.

### Type Safety
TypeScript is fully configured. Define your types in separate files or inline for better development experience with IDE autocompletion.
